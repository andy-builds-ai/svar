# knowledge — the demo corpus

Empty on purpose. Build step 2 fills this with the documents of a fictional
company, laid out the way the documents bucket expects:

```
knowledge/<workspace>/<layer>/<document>.md
knowledge/<workspace>/<layer>/<document>.md.metadata.json
```

Every document here is invented. Nothing from a real company goes in this
folder. See `docs/metadata.md` for what belongs in the sidecar file.
